Professional Self-Assessment

Through my Computer Science course, I have come to understand that creating a successful application is not just about ensuring that its functionalities are operational. It entails organizing code, selecting solutions, performing tests, and securing the data that the application handles.

This is reflected in my CS 499 ePortfolio, where I have made three improvements in an Android Inventory Management application that I had designed in CS 360. The improvements include making the application more modular with respect to models, validation, and services; implementing features like sorting, searching, and prioritization with the help of suitable algorithms and data structures; and enhancing the SQLite database of the application by using constraints, indexes, transactions, and migration techniques.

While I am still deciding on the specific field within computer science that I would like to focus on, this project has provided me with a solid understanding of software engineering, problem solving, and data management. I have also learned about the importance of revisiting existing work and improving it thoughtfully.

Project overview

This project began as an Android Inventory Management application developed for CS 360 Mobile Architecture and Programming. It provides account registration, login, and inventory management features backed by a SQLite database. During CS 499, the application was enhanced in three stages to demonstrate software engineering, algorithmic reasoning, and database design.

Completed enhancements

Enhancement One

Software Design and Engineering

Refactored the application's structure to separate data modeling, validation, business logic, and database access. Introduced InventoryItem, ItemValidator, and InventoryService to reduce duplicated logic and improve maintainability while preserving existing behavior.

Download source codeRead milestone narrative
Enhancement Two

Algorithms and Data Structures

Extended the refactored application with a merge sort for inventory ordering, case-insensitive linear search for partial matches, a PriorityQueue for low-stock prioritization, and a HashMap index for item-ID lookup. The algorithms are accessed through InventoryService, with updated search and sorting controls and unit tests.

Download source codeRead milestone narrative
Enhancement Three

Databases

Strengthened the SQLite database by relating records through numeric user IDs, adding foreign keys and constraints, adding indexes, handling search in SQL, using a transaction for account setup, and migrating from database version 3 to version 4 without deleting existing records. Tests cover database behavior and migration.
