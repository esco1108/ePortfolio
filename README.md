# CS 499 Computer Science ePortfolio

GitHub Pages portfolio for three successive improvements to an Android Inventory Management application.

- **Enhancement One:** Software Design and Engineering
- **Enhancement Two:** Algorithms and Data Structures
- **Enhancement Three:** Databases

Open [index.html](index.html) to view the page locally. To publish, add these files to the root of the `main` branch, then in GitHub repository **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/(root)`.

All three enhancements include a source-code archive and their milestone narratives under `downloads/`.

The supplied Android source code archives were repackaged without local IDE caches or generated build outputs. They have not been compiled or retested as part of portfolio packaging.
